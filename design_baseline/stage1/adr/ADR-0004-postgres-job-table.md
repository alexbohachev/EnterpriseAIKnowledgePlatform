# ADR-0004 — Job queue у PostgreSQL для MVP

**Статус:** Proposed (не підтверджено реалізацією)  
**Дата:** 2026-11-16  
**Джерела:** письмове завдання `project .txt`, транскрипції лекцій №32–33; технічний вибір — проєктна пропозиція.

## Контекст
Для невеликого навчального корпусу окремий брокер Kafka/RabbitMQ додає операційну вартість.

## Рішення
Завдання ingestion у PostgreSQL зі status, checksum, lease, retry_count. Робота worker ідемпотентна.

## Розглянуті альтернативи
Повноцінний message broker оцінити, коли з’являться дані навантаження і вимоги HA.

## Наслідки / компроміси
Плюси: простота. Мінуси: обмежена пропускна здатність і потреба в lease/retry механіці.

## Як перевіряємо
FR-10, AT-10; повторне завдання не дублює індекси.
