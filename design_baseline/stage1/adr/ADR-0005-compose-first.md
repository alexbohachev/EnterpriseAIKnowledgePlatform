# ADR-0005 — Docker Compose для демонстраційного розгортання

**Статус:** Proposed (не підтверджено реалізацією)  
**Дата:** 2026-11-16  
**Джерела:** письмове завдання `project .txt`, транскрипції лекцій №32–33; технічний вибір — проєктна пропозиція.

## Контекст
Наразі потрібен відтворюваний локальний стек, а не промислова багатозонна доступність.

## Рішення
Для першого MVP використати Compose та ізольовані мережі; фізичну схему і GPU requirement оформити окремо до реалізації.

## Розглянуті альтернативи
Kubernetes/Helm відкласти до навантаження, масштабування і вимог HA.

## Наслідки / компроміси
Плюси: простий запуск та демонстрація. Мінуси: немає промислової HA/DR з коробки.

## Як перевіряємо
Offline запуск за README, egress check, навантажувальний звіт.
