# ADR-0003 — Stateful orchestration на LangGraph

**Статус:** Proposed (не підтверджено реалізацією)  
**Дата:** 2026-11-16  
**Джерела:** письмове завдання `project .txt`, транскрипції лекцій №32–33; технічний вибір — проєктна пропозиція.

## Контекст
Потрібні відтворювані переходи стану і керовані policy gates, а не лише лінійний скрипт.

## Рішення
LangGraph підтримує explicit transitions: authorize → retrieve → validate → generate або abstain; кожен стан трасується.

## Розглянуті альтернативи
Ручна FSM також допустима в деяких варіантах, за поясненням викладача; тут обираємо LangGraph для демонстрації відповідності.

## Наслідки / компроміси
Плюси: трасованість, повторна спроба, виразна архітектура. Мінуси: залежність від оркестратора, міграції формату стану.

## Як перевіряємо
FR-09; тести переходів та відхилення неавторизованих запитів.
