# Промова на захист: 5 хвилин (версія без вигаданих результатів)

**0:00–0:40 — проблема/цінність.** Корпоративні знання розкидані по документах. Наївний LLM-пошук не гарантує ні доступу, ні доказових посилань. Ціль MVP — локальний assistant для контрольованого пошуку з цитатами та механізмом відкликання доступу.

**0:40–1:30 — системний дизайн.** На C4 показані API, PostgreSQL як джерело істини ACL, об'єктне сховище, worker, Qdrant, Neo4j, LangGraph і Ollama. Control Plane — API/орchestrator; Data Plane — індекси/модель/SQL. Двійний індекс допомагає поєднати семантичне знаходження з переходами по графу.

**1:30–2:20 — потік даних.** Завантаження PDF → extract text → chunks → embed → upsert Qdrant → upsert Neo4j → publish active run у PostgreSQL. При запиті спочатку перевіряємо ACL, далі retrieval із обох індексів, повторно перевіряємо ACL, формуємо цитати. Зовнішні індекси не є джерелом прав.

**2:20–3:15 — захист та рішення.** JWT, групи й ACL, token version, revocation, PII regex, базові prompt filters; ADR пояснюють компроміси між точністю, ізоляцією, швидкістю та вартістю. Фільтри — не повний захист, а один рівень.

**3:15–4:10 — що реально перевірено.** 37/37 deterministic tests пройшли на SQLite/fakes. Підготовлено monitoring configs і E2E/load/eval scripts. Ми НЕ підтвердили роботу всього Docker-стека, реальний graph RAG RPS, p95 інференсу чи air-gap. Немає живого відеодемо/скриншотів; заявляти зворотне було б некоректно.

**4:10–5:00 — межі MVP і дорожня карта.** Поточний варіант GraphRAG-lite, без semantic relation extraction; скани/креслення потребують OCR та мультимодального parsing. Наступні acceptance gates — live E2E A/B, measurements на GPU, monitoring screenshots, red teaming і завершення multimodal track. Заключна думка: архітектура керує довірою й доступом незалежно від поведінки LLM.

**Часті запитання викладача:**
1. Чому PostgreSQL головне для ACL, а не Qdrant? — індекс не повинен вирішувати права, особливо при revoke.
2. Чому два індекси? — Qdrant для векторного recall, Neo4j для зв'язків фрагментів; вищі витрати, потрібна eventual consistency і publication pointer.
3. Чим повний GraphRAG відрізняється? — нині лише лексичні вузли сутностей, а не доказово витягнуті типізовані відношення.
4. Чому Docker не доводить air-gap? — треба egress enforcement/сканування образів, мережеві політики, секрети.
5. Де real p95? — не виміряно; приклад healthz не переноситься на LLM.
